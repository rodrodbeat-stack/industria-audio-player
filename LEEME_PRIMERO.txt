NEURA // NEURAL AUDIO 2050 — CYBER CHAOS EDITION
================================================

ESTÉTICA
- Portada cinematográfica 888 Digital Factory / Depredador.
- HUD industrial, scanlines, interferencia/glitch, telemetría animada.
- Negro profundo, rojo de alarma, cian eléctrico y acentos verde ácido.
- Galería horizontal de álbumes, paneles de audio y centro de subida.
- Diseño adaptable a móvil y escritorio.

ARCHIVOS
- index.html: página y menús.
- styles.css: interfaz Cyber Chaos.
- app.js: búsqueda, reproductor, importación de audio, galería de fotos y conexión opcional a Supabase.
- community-config.js: configuración de Supabase.
- supabase-schema-neura.sql: configuración inicial para Storage de imágenes.
- assets/predator-cover.jpg: portada principal.

PRUEBA LOCAL
1. Descomprime el ZIP.
2. Publica los archivos en la raíz de tu repositorio GitHub Pages, conservando la carpeta assets.
3. Abre la web y prueba los menús, el desplazamiento de álbumes, el reproductor y los formularios.
4. Los audios e imágenes importados sin Supabase son locales a la sesión del navegador; no son visibles globalmente y pueden desaparecer al recargar.

CONECTAR SUPABASE (SIGUIENTE PASO)
1. Abre community-config.js.
2. Sustituye TU-PROYECTO y TU_CLAVE_PUBLICABLE_ANON por la URL y la clave pública/anon de tu proyecto.
3. Nunca pegues una clave service_role ni secretos en el frontend.
4. Revisa el esquema SQL existente de tu proyecto antes de ejecutar cambios. La tabla tracks debe tener los campos que usa app.js (artist, title, genre, description, audio_path, audio_url, status). El bucket community-audio debe existir y permitir la operación de subida según tus políticas.
5. Ejecuta supabase-schema-neura.sql para configurar el bucket de imágenes y sus políticas demo, revisándolas primero para ajustarlas a tu política de acceso.
6. Los temas se insertan como pending para moderación; no se publican automáticamente como aprobados.

NOTA
Esta edición mejora la interfaz visual; no conecta automáticamente Supabase ni reemplaza las políticas de seguridad del proyecto. La publicación global requiere credenciales y permisos correctos.
